## Lessons we learnt

- **Observation**: treesa-inf, cotengra-sa, and ten in-house mechanisms all
  converge to tc ≈ 39.95–40.1 / 61.5–62.1; cotengra-hyper (no SA
  refinement) stays 1.7–2.4 behind. **Root cause**: SA-style local
  refinement — from either codebase — reaches the same basin at 90 s; the
  differentiator is refinement, not the optimizer brand, the move set, the
  constraint handling, or the sc objective (under pure tc the same trees
  win). **Evidence**: pure-tc reference rows this cycle; ten-mechanism
  convergence (cycles 2–3). *Confirmed.* **Implication**: "we beat
  cotengra 4–90×" does not survive the cotengra-sa row; the defensible
  claims are (a) hyper-optimization alone under-refines at matched budget,
  and (b) all known refiners hit a common frontier — is it optimal? Only a
  lower bound can say (next cycle's core question).
- **Observation**: 019's structured sweeps lost by ~40 tc on the instance
  they were designed for. **Root cause**: caterpillar/linear fronts pay
  the full spacetime cross-section; branching trees found by undirected
  search realize strictly better cuts; BFS layering cannot recover flat
  time slices because depth mixes space and time hops. *Confirmed.*
  **Implication**: structure exploitation on this proxy is closed; if
  structure ever helps it needs real separator machinery (exact
  nested dissection), folding into next cycle's hierarchical-exact track.
- **Observation**: unbounded sc left the frontier unchanged.
  **Root cause**: on both instances the min-tc trees have near-minimal sc
  — the cap was never binding at the optimum, only during search
  trajectories. *Confirmed.* **Implication**: the cycle-2 "sc_target=cap"
  principle refines to "don't let sc_target sit far BELOW the natural sc
  of good trees" — the harm is one-directional; sc_target=∞ is equally
  good here and simpler. The omeco fix should default to ∞ (pure tc)
  unless the user supplies a real memory budget.

### Evidence carried forward

- Frontier: 39.95 / 61.54 (ref:treesa-inf, pure tc), reproduced by two
  independent toolchains; nothing known beats it at 90 s single-thread.
- cotengra-sa ≈ frontier (Δ ≈ 0.05/0.5); cotengra-hyper ≠ frontier.
- Blacklist: structure-guided sweeps on layered RQC proxies (019);
  move-set/constraint-handling variations (020 closed the direction).
- Unknown: distance from the frontier to the true optimum — no lower
  bound exists yet. This is the highest-value open measurement.

### Literature check

The two-toolchain convergence matches the anytime-plateau picture in
[gray_2020_hyper]; the sc_target finding now reads as "aspirational
low-memory targets are harmful, unconstrained tc is safe" — consistent
with [kalachev_2021_multi]'s overflow-penalty-only design (β penalty
activates only above the cap, never below: exactly the one-directional
harm we measured). Lower-bound machinery for next cycle is catalogued:
PID/minor-based LB [tamaki_2017_positive, tamaki_2022_heuristic].
