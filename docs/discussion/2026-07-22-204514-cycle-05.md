## Lessons we learnt

- **Observation**: three separate local wins at scale (028: 133.57, 106.30;
  030: 106.28) all evaporated in scored runs; every scored result landed
  0.5–5 worse than the same code's local best. **Root cause**: at n ≥ 1000
  with 90 s budgets, single-run variance (±1–5 log2) exceeds real method
  differences (±0.2–0.5); the confirm-twice record protocol correctly
  blocks lucky records but symmetrically prevents genuine sub-variance
  improvements from registering. The scoring design, not the algorithms,
  is the binding constraint at scale. **Evidence**: reference rows
  themselves spread 106.5–111.4; 028/030 LOG vs report deltas.
  *Confirmed.* **Implication**: scale records need variance-aware scoring
  (median-of-k) or larger budgets — a gate design decision for the user.
- **Observation**: 026's bound collapsed; 027 nulled with fat-shelf
  inversion. **Root cause**: (026) min-over-all-subsets b(k) lets a
  skewed tree hide all cost in one balanced node — the relaxation, not
  the idea, failed; (027) at the frontier, total flops behave as if
  conserved under profile reshaping — width reduction is paid in
  near-max multiplicity. **Evidence**: 026's gap table + skew diagnosis;
  027's histograms (37/7 → 36/18–19 at equal tc). *Confirmed.*
  **Implication**: the profile OPTIMIZER direction is closed (both
  pre-registered criteria hit); the profile CERTIFICATION direction is
  strengthened — the dyadic-window bound plus the conservation
  observation is the paper's Theorem 2 candidate.
- **Observation**: an attempt's failure analysis exposed a solution-space
  cap in the harness itself (scorer depth limit). **Root cause**: default
  recursion limits + deeply nested writejson trees; good RQC orders are
  inherently deep, so the limit was not neutral — it biased the admissible
  space against exactly the tree class one hypothesis needed.
  *Confirmed.* **Implication**: harness fixed, controls re-passed;
  methodological narrative gains a third case study (illusory gains twice,
  and now an invisible constraint — all caught by the loop's own
  instruments).
